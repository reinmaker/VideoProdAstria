## Scene 2: What is Astria (10s)
Astria is an AI image generation platform built for fashion and product workflows. You can generate studio-quality photos of clothing, accessories, and full outfits — using your own product images as the source of truth.

## Scene 3: What is a Reference (12s)
The key concept in Astria is the **reference** — also called a tune. A reference is a trained model built from photos of a specific product. When you add a reference to your prompt, the AI generates images that accurately show that exact item. You're not describing clothing in words — you're pointing to the real product.

## Scene 4: Demo — Workspace & References (28s)
Here's how it works. We start on the Generate page. First, we select the Zara workspace — this switches the prompt editor to show Zara's product catalog. [pause 1.0s] To add a reference, we type the at symbol in the prompt field. A picker appears showing all available product references for this workspace. We search for shirt, then pants, then shoes — selecting one tune for each. Each chip you see in the editor is a reference to a specific real product.

## Scene 5: Demo — Settings & Generate (18s)
Now we configure the generation. We set the model — Nano Banana 2 for fast, high-quality results. The ratio is set to three-by-four for portrait, the resolution to four K, and we generate two images. [pause 0.5s] Then we click Generate. Astria combines all three references and the prompt to produce a full lookbook photo featuring the exact shirt, pants, and shoes from the catalog.
